Bank Loan Analysis Dashboard | Excel & Power BI

Developed an interactive Bank Loan Analysis Dashboard to transform raw loan application data into actionable business insights.

The project analyzes loan applications, funded amounts, received amounts, loan performance, borrower characteristics, loan purposes, and portfolio trends.

Key work included data cleaning, transformation, KPI development, analysis, dashboard design, and interactive reporting.

Key KPIs included Total Loan Applications, Funded Amount, Amount Received, Average Loan Amount, Interest Rate, Good Loan Percentage, Bad Loan Percentage, and loan performance trends.

Tools Used:
Microsoft Excel | Power BI | Power Query | DAX

Business Value:
The dashboard enables management to monitor lending performance, understand borrower behavior, identify portfolio trends and potentially higher-risk segments, and make data-driven decisions.
